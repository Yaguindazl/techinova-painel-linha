# Checklist de Code Review

- [ ] O código está funcionando de acordo com o objetivo da alteração?
- [ ] O código está organizado e fácil de entender?
- [ ] Existem erros ou possíveis bugs?
- [ ] Existem problemas de segurança?
- [ ] A alteração está de acordo com o padrão do projeto?
- [ ] Existem partes desnecessárias ou código que poderia ser melhorado?
